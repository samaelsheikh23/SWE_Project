# One_Day_Hospital

## Project Overview
One_Day_Hospital is an appointment-booking system for a one-day hospital/clinic. It helps patients register or log in, browse medical specialties, choose a doctor, view available appointment times, and book a suitable appointment.

The patient visits the clinic to confirm the booking and pay in person. Online payment is not included in the current scope.

## Project Vision
Make clinic appointment booking clearer and more organized for patients and clinic staff.

## Main Features
- Patient registration and login
- Browse medical specialties
- View doctors under each specialty
- View each doctor's available appointment times
- Book an available appointment
- Manage an appointment: update or cancel a booking
- Confirm the booking at the clinic
- Pay at the clinic (no online payment)

## GitHub Workflow
All team members should work on separate branches and submit Pull Requests for review before merging changes into `main`.

1. Create a branch for your task.
2. Make a focused change and commit it with a clear message.
3. Push the branch to GitHub.
4. Open a Pull Request.
5. Ask a teammate to review it.
6. Merge only after the required approval.
